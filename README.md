# 懒人相机

> 不会拍，就照着模板拍。

一个原生微信小程序：选场景 → 看构图引导 → 按快门 → 裁剪保存。相机预览上直接叠出「人物站这里」「地标放这里」，把构图变成可以直接对进去的框。

零依赖、零后端、不上传照片，所有记录与图片都留在当前设备。

---

## 功能

**发现页**
- 3 大类 9 个模板：旅行/景点、咖啡馆/室内、双人合照
- 分类筛选、最近使用、从相册选图直接编辑
- 模板图为空或加载失败时展示本地示意图，不出现破图

**模板详情**
- 这张照片要解决什么问题
- 现场指引：拍摄者 / 被拍者 / 构图重点 / 适用条件 / 拍不好怎么办
- 按步骤拍摄、收藏模板
- 分享模板卡片，好友打开后直达同款模板页

**拍摄引导**
- 相机取景框按目标画幅显示：竖幅 3:4、横幅 4:3，避免“看到什么就拍到什么”与成片不一致
- 人物框 / 主体框 / 取景安全区 / 九宫格，可随时隐藏引导和网格
- 引导位置一键左右镜像；标签与角色不互换
- 真实步骤导航：上一步 / 下一步，步骤数与模板数据一致
- 横竖屏变化时重新计算取景框尺寸
- 重力感应水平提示只在本页可见时运行，离开页面自动释放
- 拍摄后按目标比例居中裁剪，再进入结果页

**编辑**
- 7 种比例：原图 / 3:4 / 4:5 / 1:1 / 9:16 / 4:3 / 16:9
- 3 种色调，强度 0–100% 可调
- 左转 / 右转 90°、水平镜像
- 从模板进入时可一键套用同款色调，不自动叠加
- 撤销 / 重做最近 20 步：裁剪、缩放、方向、色调均可回退
- 单指拖动、双指缩放，画面所见即导出所得
- 重新编辑已保存作品时不会自动叠加原有色调
- 按住对比原图
- Canvas 2D 导出，最长边最高 2560px

**我的作品**
- 收藏模板、最近使用、作品列表
- 作品详情：再次拍摄、重新编辑、保存到相册
- 作品分享卡片：用本机照片做封面，落地到关联模板或首页
- 删除单条作品或清空本地记录，同时清理本机缓存图片
- 隐私说明

**数据看板**
- 本机记录模板浏览、开始拍摄、保存作品、分享四类事件
- 展示相邻步骤转化率和热门模板
- 最多保留最近 500 条事件，可一键清除；不上传服务器

## 快速开始

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择本目录
3. 在 `project.config.json` 中把 AppID 换成你自己的
4. 编译运行

无需 `npm install`，无需构建步骤。

真机使用前，请在小程序管理后台配置《用户隐私保护指引》，声明**摄像头**和**相册（写入）**用途。未配置时，`wx.saveImageToPhotosAlbum` 等接口可能返回 `errno 112`。

## 加一个模板

只需要往 [data/templates.js](data/templates.js) 的数组里追加一个对象：

```js
{
  id: 'travel-landmark',
  category: 'travel',
  categoryName: '旅行/景点',
  title: '地标同框·单人全身',
  visualClass: 'visual-landmark',   // 示意图样式，公共样式在 app.wxss
  people: '单人',
  orientation: '竖幅',              // 竖幅使用 3:4，横幅使用 4:3
  difficulty: '入门',
  problem: '让人物和地标都完整出现。',
  cameraGuide: '退后 3–5 步，手机放在胸口高度。',
  subjectGuide: '站在画面左下方，身体轻转向地标。',
  focus: '平视或轻微低机位，顶部给地标留空间。',
  conditions: '适合单人、竖拍；人物距背景 1–3 米。',
  fallback: '地标放不全时，改拍半身并保留标志性局部。',
  editStyle: { filter: 'warm', level: 70 }, // 可选：编辑页「模板同款色调」
  steps: ['第 1 步', '第 2 步', '第 3 步'],
  overlay: {
    personLabel: '人物站这里',
    objectLabel: '地标放这里',
    personClass: 'person-left-bottom',
    objectClass: 'object-right-top'
  }
}
```

`personClass` / `objectClass` 的位置样式位于 [pages/camera/camera.wxss](pages/camera/camera.wxss)，新增位置时补一条样式，并在 `camera.js` 的 `PERSON_MIRROR` / `OBJECT_MIRROR` 中登记左右镜像关系。示例图路径集中在 `sampleImages` 映射中，没有图时会自动使用本地示意图。`editStyle` 可选，`filter` 取 `warm` / `fresh` / `vintage`，`level` 取 0–100；不提供时编辑页不显示「模板同款色调」。

## 技术链路

```
相机预览 <camera>
   └── 引导层 <cover-view>（安全区 / 网格 / 人物框 / 主体框 / 水平提示）
         └── 快门 wx.createCameraContext().takePhoto()
               └── 比例裁剪 隐藏 Canvas 2D（最长边 2560）
                     └── 结果页：重拍 / 编辑 / 保存
                           ├── 相册 wx.saveImageToPhotosAlbum
                           └── 作品 压缩至最长边 1800 → USER_DATA_PATH/works
                                 └── storage：最多 30 件，淘汰或删除时清理文件
```

几个关键点：

- **引导层不进成片**。`takePhoto()` 只取 `camera` 画面，`cover-view` 只是预览上的同层覆盖层。
- **预览和导出使用同一套裁剪数学**。`utils/crop.js` 负责基准缩放、偏移约束、源图裁剪矩形和输出尺寸；编辑页的 CSS transform 与 Canvas 导出共用这套计算，旋转与镜像也使用同一组变换顺序，避免“预览对了、导出偏了”。
- **作品图片是持久化副本**。不再使用已停止维护的 `wx.saveFile`，而是压缩后复制到 `wx.env.USER_DATA_PATH/works`，删除记录时同步删除文件，避免占用空间只增不减。
- **调色是颜色叠加，不是真正的滤镜**。在 Canvas 上盖一层半透明色块，强度按 0–100% 缩放；轻量、无需引入库，代价是色调偏淡，无法精确调参。

## 数据与隐私

- 收藏：`lazy_camera_favorites`
- 最近使用：`lazy_camera_recent`，最多 6 条（首页展示前 3 条）
- 作品：`lazy_camera_works`，最多 30 件
- 埋点：`lazy_camera_analytics`，最多 500 条事件（仅模板 ID、标题、来源、时间，不含照片）
- 照片持久化目录：`wx.env.USER_DATA_PATH/works`
- 不上传任何照片，没有服务器，没有账号体系
- 数据看板只统计本机操作，可单独清除
- 清空记录只影响本机缓存，不会删除手机相册中的照片
- 作品分享的落地页是关联模板或首页；作品记录本身不会随分享链接传播

## 验证建议

建议在真机上至少走一遍以下路径：

1. 竖幅模板：拍摄 → 结果页 → 编辑 → 保存，确认相册与「我的作品」同时出现
2. 横幅模板：确认取景框为 4:3，成片比例与预览一致
3. 拒绝相册权限后再次保存，确认引导去设置
4. 双指缩放、拖动后导出，确认裁剪位置与预览一致
5. 依次切换 4:5、16:9，再左转/右转与水平镜像，导出后确认方向、比例与预览一致
6. 选择色调后拖动强度滑杆，再连续撤销/重做，确认画面与按钮状态同步
7. 从模板进入编辑，确认「模板同款色调」按钮与模板匹配，且不会自动套用
8. 连续保存超过 30 件，确认最旧作品及本地文件被清理
9. 拍摄中切后台再回来，确认水平提示恢复且没有重复监听
10. 从模板页分享给好友，确认卡片落地到同一个模板
11. 浏览、拍摄、保存、分享后打开「我的 → 数据看板」，确认计数与转化率变化，再清除统计
