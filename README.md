# 懒人相机

> 不会拍，就照着模板拍。

一个微信小程序：选场景 → 看构图引导 → 按快门 → 保存。专治"站好了，然后拍糊了/人没进框/地标被切掉"。现在只添加了几个模块和滤镜

原生小程序实现，**零依赖、零后端、零上传**。

---

## 它解决什么

拍照类 App 的问题是：参数给了，姿势也给了，但**用户不知道该把画面里的人放在哪**。

懒人相机的做法是把"构图"变成一层可视化的框：相机预览上直接叠出「人物站这里」「地标放这里」，用户只需要把人和物**对进框里**。引导层是 `cover-view`，只用于取景，**不会出现在成片里**。

## 功能

**拍摄引导**
- 3 大类 9 个模板：旅行/景点、咖啡馆/室内、双人合照
- 每个模板拆成"拍摄者怎么做 + 被拍者怎么做"，各一句话
- 相机页实时叠层：人物框 / 主体框 / 取景安全区 / 九宫格
- 引导位置可一键左右翻转（换机位、换构图方向时用）
- 顶部可随时隐藏引导、开关九宫格、切换前后镜头

**模板详情页**
- 这张照片要解决什么问题
- 现场指引：拍摄者 / 被拍者 / 构图重点 / 适用条件 / 拍不好怎么办
- 拍摄 3 步走，收藏模板

**拍后处理**
- 重拍 / 保存到相册
- 裁剪调色：5 种比例（原图 / 3:4 / 4:3 / 1:1 / 9:16）+ 3 种色调（暖调 / 清透 / 复古）
- 按住对比原图

**我的**
- 收藏模板、最近使用（只存在本机）
- 一键清空本地记录（不动相册照片）

## 快速开始

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择本目录
3. AppID 填**你自己的**（`project.config.json` 里目前是作者的）
4. 编译运行

真机预览需要在小程序后台配置 **相册权限** 用途说明，否则保存会失败。

无需 `npm install`，无需构建步骤。

## 加一个模板

只需要改 [data/templates.js](data/templates.js)，一行一个：

```js
make(
  'travel-landmark',        // id
  'travel',                 // 分类
  '旅行/景点',              // 分类名
  '地标同框·单人全身',       // 标题
  'visual-landmark',        // 示意图样式类
  '单人',                   // 人数
  '竖幅',                   // 画幅
  '让人物和地标都完整出现。', // 要解决的问题
  '拍摄者：退后 3–5 步……',  // 拍摄者指引
  '被拍者：站在画面左下方……',// 被拍者指引
  '平视或轻微低机位……',     // 构图重点
  '适合单人、竖拍……',       // 适用条件
  '地标放不全时，改拍半身……',// 兜底方案
  ['第 1 步', '第 2 步', '第 3 步'],
  {                         // 引导层：位置 + 文案
    personLabel: '人物站这里',
    objectLabel: '地标放这里',
    personClass: 'person-left-bottom',
    objectClass: 'object-right-top'
  }
)
```

位置类名（`personClass` / `objectClass`）在 [pages/camera/camera.wxss](pages/camera/camera.wxss) 里定义，新增位置时补一条样式即可。

## 技术链路

```
相机预览  <camera>
   └── 引导层  <cover-view>（人物框 / 主体框 / 网格 / 安全区）
         └── 快门  wx.createCameraContext().takePhoto()
               └── 保存  wx.saveImageToPhotosAlbum()
                     └── 编辑  CanvasContext 裁剪 + 颜色叠加 → wx.canvasToTempFilePath()
```

两个关键点：

- **引导层不进成片**。`takePhoto()` 只取 `camera` 组件画面，`cover-view` 是原生组件之上的同层渲染图层，所以引导线再花也不会污染照片。
- **调色是颜色叠加，不是滤镜**。"暖调/清透/复古"本质是在 canvas 上盖一层半透明色块——比引 WebGL 或第三方滤镜库轻得多，代价是色调偏淡、无法精确调参数。要真滤镜时换 `Canvas 2D` + `getImageData`。

## 数据与隐私

- 收藏、最近使用存在 `wx.setStorageSync`（`lazy_camera_favorites` / `lazy_camera_recent`），最多 6 条最近记录
- **不上传任何照片**，没有服务器，没有账号体系
- 拍摄、编辑、保存全在本机完成

## 当前版本不包含

云端同步 · AI 识别 · 实时姿势检测 · 视频拍摄 · 模板市场 · 社交分享

第一版只验证一件事：**单人「地标同框·竖幅全身照」能否在 iOS/Android 真机上从打开相机一路走到保存成功。**
